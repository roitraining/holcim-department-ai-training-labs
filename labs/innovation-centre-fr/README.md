# L’IA pour le Holcim Innovation Centre : ateliers

Cinq ateliers pour l’après-midi Gemini du HIC. Chaque dossier contient `lab.md`, `images/` et `assets/`.

| Atelier | Dossier | Durée |
| :--- | :--- | :--- |
| Ingénierie de prompts avancée | `lab-01-advanced-prompt-engineering/` | 30 minutes |
| Gemini dans Gmail | `lab-02-gemini-in-gmail/` | 30 minutes |
| Présentations conformes à la charte Holcim avec Gemini dans Google Slides | `lab-03-presentations-from-docs-and-sheets/` | 30 minutes |
| Analyser les données d’essai du HIC avec Sheets et Gemini | `lab-04-analyzing-trial-data-with-sheets-and-gemini/` | 30 minutes |
| Note de synthèse sur l’essai de liant avec Gemini Notebook | `lab-05-binder-trial-briefing-with-gemini-notebook/` | 30 minutes |

## Fichiers de cours

Les fichiers de cours sont **en anglais** : ce sont les mêmes que ceux de la version anglaise des ateliers. Les consignes et les prompts sont en français, et les prompts demandent à Gemini de répondre en français lorsque c’est utile.

Tous les fichiers nécessaires se trouvent dans un dossier Google Drive public (toute personne disposant du lien peut le consulter). Chaque `lab.md` renvoie vers chaque fichier à l’étape où il est nécessaire, et indique précisément comment l’utiliser : le télécharger, puis l’importer dans Gemini, Drive, Docs, Sheets ou NotebookLM. Aucune préparation ni aucun partage par le formateur n’est nécessaire.
